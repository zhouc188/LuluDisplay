# LuluDisplay

使用 Swift 6、SwiftUI 和 AppKit 编写的 macOS 菜单栏应用。部署目标为 macOS 14.0，主要面向 Apple Silicon。

## 构建与运行

使用带 macOS 26 或更新 SDK 的 Xcode 打开 DesktopControl.xcodeproj，选择 DesktopControl scheme 并运行。该 scheme 包含纯逻辑 XCTest。

只有 Command Line Tools 时，可在项目目录运行以下命令。

```sh
bash ./setup-local-signing.sh # 本机首次配置一次，后续保留此身份
app="$(./build-local.sh)"
open "$app"
./test-local.sh
```

脚本会先构建并验证签名，再更新「应用程序」中的 LuluDisplay.app。可传入其他输出目录用于测试构建。应用从菜单栏的显示器图标打开，内有设置和退出入口。登录时启动使用 macOS 登录项管理。

本机签名保存在 `~/Library/Application Support/LuluDisplay/Signing` 的独立钥匙串中，不更改系统证书信任设置。不要删除或重建此目录，否则旧授权可能失效。构建时也可通过 `LULUDISPLAY_SIGN_IDENTITY` 指定已有开发者证书。安装脚本会拒绝与已安装证书身份不一致的更新。Xcode 工程使用同一本机证书，构建前需解锁该钥匙串（运行一次构建脚本即可）。首次从临时签名迁移后，请在系统设置中移除旧授权条目，重新添加 `/Applications/LuluDisplay.app` 并授权一次。

窗口设置每秒刷新权限，也提供「重新检测权限」。授权判断同时参考系统信任状态和实际的只读辅助功能请求，不把超时或不支持的目标当成已授权。若系统开关已开启却仍失败，先退出再打开应用，再检查授权条目是否指向「应用程序」里的当前版本。

退出日常运行的 LuluDisplay 后，可在已解锁的 macOS 桌面运行 `./test-appkit.sh`。测试通过临时应用打开菜单栏和设置窗口。在有两台独立显示器时，测试会短暂启用副屏遮罩并发送进程内恢复事件。测试不会写入显示器硬件亮度。

## 使用

面板上方会明确区分「同步亮度」和「主屏亮度」，显示当前可调节的参与数量。关闭同步时，主滑杆调主屏，F1/F2 仍调鼠标所在屏幕。无可用亮度通道或没有同步成员时，滑杆不可用；硬件亮度与软件调暗分开标明。分辨率详情及校准放在展开区域；内容过长时整体滚动，窗口布局图标、吸附与刘海开关，以及设置、恢复和退出固定在底部。

软件调暗重新探测或恢复后会清除遮罩，主亮度同步回到当前无遮挡状态，下一次降低键从 100% 降至 95%。硬件屏恢复仍先撤遮罩，再请求可视硬件亮度。

macOS 26 及以上的菜单面板和亮度提示使用原生 Liquid Glass，较旧系统使用标准材质。开启系统「减少透明度」时改用不透明背景。设置采用原生分组表单，数字过渡和按压反馈遵循「减少动态效果」。

- 主亮度支持绝对和相对同步，后者按参与屏幕的偏移和上下限映射。硬件不可用时可按屏幕启用软件调暗，百分比代表遮罩控制量。
- 内置屏自动探测硬件亮度，包括动态加载的 Apple DisplayServices 通道，成功写入后读取实际值。外接 Apple 显示器及 DDC 的兼容探测仍需在设置中开启；这些兼容通道涉及未公开接口，只有匹配目标并读取有效值时才使用。
- 内置主屏的硬件亮度约每 2 秒回读到界面，独立于「外接屏跟随」开关。软件调暗的 100% 仅代表无软件遮罩，不能代表硬件最大亮度；无硬件通道且无遮挡的单内置屏会放行原生亮度键。应用不修改系统自动亮度、HDR 预设或系统亮度限制。
- 当选用可读硬件亮度的内置屏作为同步主屏时，可开启外接屏跟随。应用约每 2 秒读取一次内置屏亮度，以跟随 macOS 自动调光和手动调整。跟随的最低亮度为 1%。
- 0% 使用纯黑覆盖层。紧急恢复默认是 **⌃⌥⌘B**。首次尝试全屏组全黑时，先在可视状态按下恢复快捷键，再重新设为 0%。第一次试用将在 8 秒后自动解除。提高亮度快捷键默认是 **⌃⌥⌘↑**，也可解除全黑。
- 持续按降低亮度键触及 0% 时，若本次启动尚未完成恢复验证，会主动显示「同步全黑前验证恢复键」，并保持之前的非零亮度。提示位于调暗遮罩上方。按提示验证后再降到 0%，参与同步的显示器都会应用完全不透明的黑色遮罩；非零低亮度的肉眼效果仍受显示器本身影响。
- 分辨率八档依次为 1280×720、1600×900、1920×1080、2048×1152、2560×1440、3008×1692、3360×1890、3840×2160。切换只用系统可用的模式，确认时限为 15 秒。显示详情区分逻辑尺寸、模式像素和 HiDPI。
- 左右半屏、最大化、居中、跨屏移动和拖拽吸附需要 macOS 辅助功能权限，可从窗口设置进入授权。显示器调节、紧急恢复组合键和刘海外观独立于该权限。
- 菜单栏提供「上三分之一」「下三分之二」，按当前窗口所在屏幕的可用区域分配高度，扣除窗口间距后保持 1:2。默认快捷键分别为 **⌃⌥↑** 和 **⌃⌥↓**，可在通用设置修改。
- F1 / F2 以及键盘上的太阳亮度键可按当前同步设置降低 / 提高 5% 亮度，支持长按。需要辅助功能授权；通用设置显示按键接入状态。带 Command、Control、Option 或 Shift 的功能键组合和音量键保持原行为。无法调节、锁屏或安全输入时不接管亮度键。降低到 0% 仍须通过原有恢复验证。
- F1/F2 开启同步时调节所有参与屏幕，关闭同步时按按键瞬间的鼠标位置选择屏幕，不更改设置中的主屏。鼠标所在屏幕会显示目标百分比提示，最后一次按键后约 1.2 秒自动消失，不抢焦点或拦截鼠标。提示显示的是请求目标；硬件实际回读仍在显示器卡片中显示。进入 0% 时隐藏提示以保持全黑。
- 亮度键监听每秒检查一次，停用时恢复，端口或事件源失效时重建；会话休眠时停止，恢复时重新连接。亮度键权限检测独立于当前应用的窗口辅助功能状态，不依赖打开设置页。`bash ./test-keyboard-recovery.sh` 使用已有本机签名与授权测试真实事件监听的恢复，不吞按键或修改硬件亮度。
- 带刘海的内置屏可开启黑色菜单栏衬底。快捷键可在通用设置修改。
